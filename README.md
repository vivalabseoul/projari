# 프로체어 (ProChair) MVP

미용실의 비어 있는 의자(체어)를 검증된 미용인에게 온라인으로 임대하는 플랫폼의 화면 프로토타입입니다.
주 고객은 임대인(원장님)입니다.

> `js/env.js`가 비어 있으면 **시연 모드**입니다. 로그인·결제·저장이 동작하지 않고 화면의 매장·금액은 모두 예시 데이터입니다.
> Supabase 키를 넣으면 **운영 모드**로 바뀌어 실제 가입·로그인·공간 등록·예약·검수가 DB에 저장됩니다.

## 운영 모드 켜는 순서
1. [supabase.com](https://supabase.com)에서 프로젝트를 만듭니다 (리전은 Seoul 권장).
2. **SQL Editor**에 [supabase/schema.sql](supabase/schema.sql) 전체를 붙여 넣고 실행합니다. 테이블·권한(RLS)·서버 검증·파일 저장소가 한 번에 만들어집니다.
3. **Authentication → Providers → Email**에서 **Confirm email을 끕니다.** (켜 두면 가입 직후 자격 서류를 제출할 수 없습니다. 메일 인증을 쓰려면 별도 작업이 필요합니다.)
4. **Project Settings → API**의 `Project URL`과 `anon public` 키를 [js/env.js](js/env.js)에 넣습니다. `service_role` 키는 절대 넣지 마세요.
5. 사이트에서 관리자로 쓸 계정을 일반 회원으로 가입한 뒤, SQL Editor에서 한 번만 실행합니다. 관리자 권한은 화면에서 만들 수 없습니다.
   ```sql
   update profiles set role = 'admin', verified = true where id = (select id from auth.users where email = '관리자@이메일');
   ```
6. 관리자 콘텐츠·수수료 기능(광고바·공지사항·팝업·수수료율·프로모션)을 쓰려면 [supabase/admin_content.sql](supabase/admin_content.sql) 전체를 SQL Editor에서 한 번 더 실행합니다.
7. 정적 호스팅(GitHub Pages, Netlify, Cloudflare Pages 등)에 폴더째 올립니다. 관리자 화면은 `admin.html`에서 관리자 계정으로 로그인해 엽니다.

### 운영 모드에서 실제로 동작하는 것
회원가입·로그인(이메일+비밀번호), 자격증·영업신고증 업로드(본인·관리자만 열람), 공간 등록과 사진 저장, 관리자 승인 후 공개,
예약 요청(요금·중복 시간대·자격 업종은 서버가 다시 검증), 호스트 수락·거절, 월 계약 생성, 후기와 답글, 할인 설정,
관리자의 입금 확인·입주 확인·지급 완료 처리. 상세 주소와 출입 코드는 확정된 예약의 디자이너에게만 보입니다.

### 관리자 화면 (왼쪽 메뉴)
대시보드 · 자격·신고증 인증 · 입금·정산 · 운영 현황 · 광고바·공지·팝업 · 수수료·프로모션.
수수료율은 서버가 정하고, 예약이 만들어지는 순간의 요율이 그 예약에 고정됩니다(`booking_fees`). 기본 요율이나 프로모션을 바꿔도 이미 만들어진 예약·월 계약은 바뀌지 않습니다.
프로모션이 겹치면 가장 낮은 요율 하나만 적용하고, 요율 변경은 모두 `admin_log`에 기록됩니다.

### 아직 동작하지 않는 것 (운영 전 결정이 필요한 항목)
- **온라인 결제·가상계좌·자동 정산**: PG사 계약 후 연동합니다. 지금은 관리자가 입금을 직접 확인하고 처리합니다.
- **휴대폰 문자 인증, 카카오 로그인, 비밀번호 재설정 메일**: 문자 발송 업체·메일 발송 설정이 필요합니다.
- **큐넷 자격 진위확인 자동 조회**: 관리자가 제출 서류를 보고 직접 승인합니다.
- **납부 알림·계약 연장 제안 알림**, **약관 본문**, **취소·환불 규정**.

## 실행
빌드 없이 `index.html`(사이트)이나 `admin.html`(관리자)을 브라우저로 열면 됩니다. GitHub Pages 같은 정적 호스팅에 폴더째 올리면 됩니다.

| 주소 | 화면 |
|---|---|
| `index.html` | 사이트 홈 |
| `admin.html` | 관리자 (자격 인증부터 시작) |
| `index.html#admin-pay` | 관리자 입금·정산으로 바로 열기 (`#역할-탭` 형식) |

## 폴더 구조
```
index.html            사이트 진입점
admin.html            관리자 진입점
css/style.css         전체 스타일
images/               예시 매장 사진
js/
  env.js              ★ Supabase 연결 키 (비우면 시연 모드)
  db.js               운영 모드: DB 읽기·쓰기, 로그인 세션, 파일 업로드
  config.js           ★ 정책 설정 (수수료·프로모션·사진 제한·업종별 이용 기준)
  data.js             예시 데이터 (매장·계약·예약·인증)
  state.js            화면 상태
  utils.js            금액·날짜 계산 등 공통 함수
  router.js           메뉴(NAV), 화면 등록(PAGES), 주소(#역할-탭) 처리
  auth.js             회원가입·로그인 (프로토타입)
  payment.js          결제 확인 창
  photos.js           매장 사진 업로드 (5장, 장당 100KB 자동 축소)
  events.js           클릭·입력·제출 처리
  main.js             시작
  pages/
    home.js           홈, 마이, FAQ, 푸터
    hostcenter.js     원장님 소개 (호스트센터)
    guide.js          이용 안내
    host.js           원장님: 대시보드·월세 관리·입점 요청·정산 내역·공간 등록
    reviews.js        후기
    guest.js          디자이너: 공간 찾기·상세·내 예약
    admin/
      verify.js       관리자: 자격·신고증 인증
      payments.js     관리자: 입금·정산 (입금 확인 / 정산 확인 / 대사)
      ops.js          관리자: 운영 현황
```

### 관리자 화면 추가하는 법 (예: 회원 관리)
1. `js/pages/admin/members.js` 만들기 → `function adminMembers(){ return \`...\`; }` 와 `PAGES.admin.members=()=>adminMembers();`
2. `js/router.js`의 `NAV.admin`에 `['members','회원 관리']` 한 줄 추가
3. `index.html`, `admin.html`의 script 목록에 `<script src="js/pages/admin/members.js"></script>` 추가 (`js/main.js` 앞)

## 화면 구성
- **홈 / 호스트센터**: 원장님 대상 소개, 이용 안내, FAQ
- **원장님(호스트)**: 대시보드, 월세 관리, 입점 요청, 정산 내역, 후기, 공간 등록(사진 5장·장당 100KB 자동 축소)
- **디자이너(게스트)**: 공간 찾기, 상세(일·월·년 선택, 기본 일 단위), 내 예약
- **관리자**: 자격·신고증 인증, 입금·정산(입금 확인 / 정산 확인 / 대사 분리), 운영 현황

## 정책 설정 (`js/config.js`의 `CONFIG` 한 곳에서 변경)
| 항목 | 현재 값 (가안) |
|---|---|
| 플랫폼 수수료 | 일·월·년 모두 15% (월세+운영료 기준, 보증금 0%). 화면에는 공개하지 않음 (`feePublic`) |
| 수수료 할인 | 없음 (항상 15%) |
| 보증금 | 가상계좌로 수납 → 입주 확인 후 원장님께 전달, 반환은 원장님 직접 |
| 매장 사진 | 최대 5장, 장당 100KB |

업종별 이용 기준(매장 기기 / 디자이너 직접 준비 / 유의사항)은 `js/config.js`의 `TYPE_RULES` 한 곳에서 관리합니다.

## 정산 공식
```
원장님 지급액 = (월세 + 운영료) − 플랫폼수수료  [+ 보증금: 첫 달, 입주 확인 후]
플랫폼 수익   = 플랫폼수수료 − PG수수료 − 보험료
검증: 청구액 = 원장님 지급액 + 수수료 (1원 단위 일치)
```

## 확정 전 항목
구청(미용인 영업신고·일 단위 대여 가능 여부), PG사(업종 승인·지급대행·정기결제), 보험사(프로체어케어),
세무사(부가세·매출 인식), 변호사(약관·전자금융 구조) 확인 후 확정합니다.
